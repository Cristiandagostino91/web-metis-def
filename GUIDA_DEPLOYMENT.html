3. Creare Account MongoDB Atlas

MongoDB Atlas è il servizio cloud gratuito per il database.

3.1 Registrazione

1 Vai su https://www.mongodb.com/cloud/atlas/register

2 Compila il form con email, password e nome

3 Verifica l'email cliccando il link ricevuto

3.2 Creare il Cluster

4 Clicca "Build a Database"

5 Seleziona "M0 FREE" (piano gratuito)

6 Provider: AWS | Regione: Frankfurt

7 Cluster Name: CentroMetisCluster

3.3 Creare Utente Database

8 Crea utente: centrometis_admin

9 IMPORTANTE: Genera e SALVA la password!

3.4 Configurare Accesso

10 Seleziona "Allow Access from Anywhere"

3.5 Ottenere Connection String

11 Clicca "Connect" → "Connect your application"

12 Copia la connection string e sostituisci <password>

📝 Credenziali MongoDB

Connection String:

mongodb+srv://centrometis_admin:@.mongodb.net/

Database Name: centrometis

Username: centrometis_admin

Password:

4. Creare Account DigitalOcean

1 Vai su https://www.digitalocean.com

2 Clicca "Sign up"

3 Registrati con Email, Google o GitHub

4 Aggiungi metodo di pagamento

💡 Bonus: I nuovi account ricevono $200 di crediti gratuiti per 60 giorni!

5. Deploy su DigitalOcean

5.1 Creare App

1 Dashboard → "Create" → "Apps"

5.2 Connettere GitHub

2 Seleziona "GitHub" e autorizza

3 Seleziona il repository centro-metis-website

5.3 Configurare Backend

5.7 Lanciare

6. Configurazione Dominio

1 App → Settings → Domains → "Add Domain"

2 Inserisci il dominio e segui le istruzioni DNS

Sul pannello del registrar (Aruba, GoDaddy, ecc.), configura i record DNS forniti da DigitalOcean.

⏳ La propagazione DNS può richiedere 24-48 ore

7. Importare il Database

Con MongoDB Compass

1 Scarica MongoDB Compass da mongodb.com/try/download/compass

2 Connettiti con la connection string

3 Crea database centrometis

4 Importa database_export.json
